# NSZ Import Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 hick 手机中后台转换 NSZ 为经过校验的 NSP，并安全接入游戏/更新/DLC 导入。

**Architecture:** 独立 C# 转换组件完成 PFS0、NCZ solid/block 与 AES-CTR 还原。Library 桥与 Swift coordinator 各自持有任务资源，只有工作线程结束才释放；生产包分类和原子提交完成后调用已有游戏流程。转换测试、合法包导入及实际游戏运行分别验收。

**Tech Stack:** .NET 10.0.100、ZstdSharp.Port 0.8.8、NUnit 3.13.3、Swift/Foundation/SwiftUI、iOS arm64 NativeAOT。

**Spec:** `docs/superpowers/specs/2026-10-10-nsz-import-design.md`，用户已认可，当前版本 cc98ac345。

**Execution:** Native，沿用用户先前选择；主代理逐任务实现，最后独立整分支审查。

## Global Constraints

- 新增 NSZ 导入；不新增 XCZ、独立 NCZ、ZIP/7Z/RAR 或其他平台支持。
- 固定 `ZstdSharp.Port 0.8.8`，依赖/缓存/工具/输出均在 `/Volumes/untitled/github/MeloNX` 内。
- 复制缓冲 1 MiB；block exponent 14…26、Zstd window ≤128 MiB、section 1…64、PFS0 entries ≤8192、block count ≤1,048,576。
- 空间预检：完整 NSP 大小 +256 MiB；过程重新检查空间并捕获 ENOSPC。
- 原件、已有游戏、固件、keys、存档、配对保留；目标无覆盖 rename，同名生成新文件名。
- UI 消失/后台/取消撤销启动意图；未结束前不能重试、释放 handle/作用域或删除打开的临时文件。
- 先确认的取消阻止提交；提交后取消保留完成 NSP，禁止启动/注册。
- 生产分类基于 NCA/CNMT；GameInfo 不是更新/DLC 校验器；合成探针不能绕过生产校验。
- 更新/DLC 注册已提交路径，不能进入先删再复制的旧分支。
- 安装沿用 com.hick.MeloNX，原位更新；真机目标 00008130-001859C21AF3803A。

## Review Focus

- 文件提供者短读或选择后作用域释放：继续持有访问且循环 ReadExactly，不能生成截断 NSP（Task1/5）。
- NCZ first section 低于/等于/高于0x4000：仅写一次原头，前导区间从数据流读，CTR 用绝对偏移（Task1）。
- 整倍数末块、原样块与伪造目录：输出长度精确，分配前验证 count/table/entry 边界（Task1）。
- 文件提交同时取消、同名或源=目标：已取消不提交、已提交不删除、已有文件不覆盖（Task2/6）。
- 更新/DLC-only NSZ 或错误 TitleID：分类不依赖 GameInfo，直接注册合法持久路径，错误目标不启动（Task3/6）。

public sealed record NszLimits(int MaxEntries = 8192, int MaxSections = 64,
    int MaxBlockExponent = 26, int MaxBlocks = 1048576, int WindowLog = 27);
